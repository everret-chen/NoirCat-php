# 审计报告索引

本项目采用双分支策略：`main`/`dev` 是安全版，`vuln-lab` 是**故意留洞**的练习版。
每个模块完成后产出一份安全版审计报告，并在 `vuln-lab` 留下对应的可复现漏洞。

## 报告约定

每份报告包含五部分：**范围与版本 → 检查清单与结论 → 发现的问题与修复 → 验证过程 → 复盘**。

## 使用须知

- `vuln-lab` 只允许在本地/隔离环境运行，**禁止部署公网、禁止接入真实数据**；
- `vuln-lab` 的漏洞**不得合并回** `main`；
- 在 `vuln-lab` 上发现的"漏洞"是教学素材，不是缺陷，不需要修复。

详见 [.github/SECURITY.md](../../.github/SECURITY.md)。
